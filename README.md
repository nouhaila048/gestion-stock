# GRP2 Nouhaila & Maroua 

Application PHP en ligne de commande de gestion de stock (POO)

## Contrat d'interface
- Produit : reference, nom, prix, quantite, ajouterQuantite(), retirerQuantite(), valeurStock()
- Stock : ajouter(), trouver(), tous(), compter(), valeurTotale(), produitsEnRupture(), produitsSousSeuil()
- Commande : ajouterLigne(), total(), valider(), estValidee(), afficher()
